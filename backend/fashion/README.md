# Fashion Store

A modern full-stack ecommerce website for a fashion brand.

## Project Structure

- `frontend` → Customer-facing website
- `backend` → Server and API
- `admin` → Admin dashboard
- `database` → Database structure

## Frontend

- React
- Vite
- React Router
- Framer Motion
- Lucide React

## Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- Product browsing
- Search and filters
- Product details
- Cart
- Wishlist
- User authentication
- Checkout
- Orders
- Admin dashboard
- Inventory management
